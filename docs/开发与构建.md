# 开发与构建

这里的环境仅供开发者使用，发行包用户无需安装。

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -e ".[dev]"
python scripts/prepare_resources.py
cd frontend
npm ci --legacy-peer-deps
npm run build
cd ..
.venv\Scripts\python -m media_organizer serve
```

运行 `python -m pytest -q` 验证核心和 API。开发时可使用 `MEDIA_ORGANIZER_HOME` 指定状态目录，避免混用真实任务数据。`doctor` 检查城市库和媒体元数据组件。

Windows 构建：`python scripts/build_release.py`。Linux 构建前在 Ubuntu 22.04 构建机运行 `bash scripts/build_perl.sh`，把可重定位 Perl 和相应共享库打入 vendor，再执行同一构建脚本。

构建程序检查离线资源完整性，冻结 Python、服务与网页，随后在去除 Python/Node/Perl 环境路径且设置不可用网络代理的环境中，验证冻结程序的启动、复制、SHA-256、源文件保留和快速校验删除门控，再生成 ZIP 或 TAR.GZ。

`.github/workflows/release.yml` 为 Windows 和 Linux 构建并测试免安装包。推送与 `pyproject.toml` 中版本一致的 `v` 前缀标签后，两端验证通过才会上架到 GitHub Releases，同时附上 `SHA256SUMS.txt`。推送 `main` 或在分支上手动运行时，产物保存在 Actions 中。

目录职责：

- `src/media_organizer/engine.py`：扫描、计划修正、非覆盖复制、恢复、校验、报告。
- `metadata.py` / `geography.py`：媒体规则与离线地点匹配。
- `filedata.py` / `paths.py`：内容散列、附加数据、跨进程锁、路径边界。
- `store.py`：SQLite 持久清单与任务状态，分页读取。
- `api.py` / `cli.py`：共用核心的两个入口。
- `frontend/`：全本地 Vue 界面。
- `scripts/`：官方资源准备、两端打包、冻结程序冒烟检查。

首次执行前计划可编辑；执行后计划冻结。所有源文件均只读；目标冲突不会覆盖。报告落盘之前不暴露“完成/可删除源目录”状态。城市名和文件名经过跨平台路径清理，目标目录中的符号链接不可用于逃逸目标根目录。
