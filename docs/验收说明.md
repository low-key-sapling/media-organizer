# 验收说明

## 验证入口

- 共享核心与 API：`python -m pytest -q`。
- 网页：`node scripts/ui_test.mjs`，测试系统 Edge 中的扫描、目录浏览、取消延迟响应、预览修正、复制校验、CSV、设置、历史及窄屏布局；拦截全部外部网络请求并检查浏览器运行错误。
- 冻结程序：`python scripts/smoke_release.py <发行包主程序>`，移除开发工具路径、清除 Python/Perl/Node 环境变量并设置不可用网络代理，验证真实发行程序的 CLI、本地 HTTP 服务、网页资源、元数据工具、中文及空格路径、离线 GPS、复制、完整校验与快速校验删除提示限制。
- 两端构建：<https://github.com/low-key-sapling/media-organizer/actions/workflows/release.yml>。

## 数据完整性重点

测试包含零字节文件、隐藏文件、配套文件、同名同内容复用、同名不同内容保留、同大小内容损坏、源文件新增/修改/消失、校验后目标发生变化、任务中断恢复、报告写入失败、跨进程锁、路径逃逸、目录联接以及不支持硬链接时的独占复制。并发出现的目标文件不会被错误清理。

Windows ADS 和 Linux user.* 扩展属性分别在各自系统测试。符号链接用例在未开启相关权限的 Windows 上会跳过，目录联接用例仍会运行；Linux 会验证符号链接和用户扩展属性。操作系统专属用例在另一平台跳过。

## 首次规模基线

2026-11-25，在本机 Windows 上创建 100,000 个空普通文件进行清单测试：扫描约 63.97 秒，末页 50 项查询约 31 毫秒，状态库约 97.7 MB。测试目录位于项目缓存，全部为生成的测试文件。

该基线只验证大量文件清单与分页，不代表真实媒体的元数据读取速度，也不代表 TB 数据的复制吞吐。真实视频复制和全量校验主要受磁盘、文件大小、文件系统与设备连接影响。

首次两端 CI 通过记录：<https://github.com/low-key-sapling/media-organizer/actions/runs/45581717783>。最终发行请以对应源码提交的 CI 结果和该次产物为准。
