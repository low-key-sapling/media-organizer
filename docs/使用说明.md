# 媒体整理器使用说明

## 开箱即用

Windows：解压发行 ZIP，在可写目录中双击 `media-organizer.exe`。Linux：解压对应 x64 TAR.GZ，运行 `./media-organizer`。无需安装 Python、Node 或 Perl；首次运行也无需联网。程序使用现有系统浏览器展示界面。

后台程序运行时，关闭浏览器不会停止任务。退出后台程序可中断任务，下次启动后继续。整个发行目录需保留；不要只复制其中的 EXE。任务数据库默认位于程序旁的 `user-data` 目录，请随程序一起保留。

## 整理流程

1. 选择源目录和独立的目标目录。两者不能相同或互相包含；程序的工作数据目录也必须位于源目录之外。若程序解压在待整理目录内，先将整个程序目录移到外面再启动。
2. 选择快速、抽样或完整校验，点击“扫描并预览”。此阶段不复制文件。
3. 检查文件类型、月份、归档子目录和目标路径。勾选文件可批量修正。修改只应用于整理预览。
4. 确认后复制，查看执行与校验进度。
5. 查看结果，导出 CSV 清单。报告也保存在目标目录 `.media-organizer/reports/<任务编号>/`。

类型包括 `photos`、`images`、`videos`、`audio`、`documents`、`archives` 和 `others`。明确是图片但缺少拍摄线索时归入 `images`。

- 文档的路径为 `documents/YYYYMM/后缀/文件名`，例如 `documents/202611/pdf/合同.PDF`。后缀目录统一使用小写。手动归为文档的无后缀文件使用 `others`。
- 其余类型使用 `类型/YYYYMM/地点/文件名`。地点缺失或无法匹配时使用 `others`。

新扫描的任务会使用新规则。续跑或校验已有任务时，以清单中保存的目标路径为准。

照片识别采用元数据线索，不能保证来源判断准确。日期优先读取明确的拍摄/录制字段，再识别文件名中明确的 YYYYMMDD / YYYY-MM-DD / YYYY_MM_DD 日期，最后回退修改时间。月份保留记录中的当地日期。不会把音频发行年份或含义不明确的视频容器创建时间直接当作录制时间。

地点优先文件中的拍摄地点文字，其次离线 GPS 城市点匹配；默认最大匹配距离 100 公里，可在设置调整。英文或拉丁转写地名按 `国家_省份_城市` 命名。GPS 匹配为近似结果，边界附近可能有偏差；冲突在预览里标记。

## 校验与源目录

- 快速：逐文件核对对应关系、目标存在性和文件大小。
- 抽样：快速检查，加随机 10% 文件的 SHA-256，至少一个。
- 完整：全部文件逐一比较 SHA-256，默认采用此级别。

所有档位都重扫源目录，发现新增、修改、消失、读取失败或未处理项时阻止删除提示。仅当完整校验全部通过、报告成功保存且没有未处理项目时，提示可手动删除源目录。程序没有删除源目录的功能。

提示针对本次校验时点；若之后继续向源目录添加或修改文件，应重新扫描整理。内容校验不证明类型、日期、地点判断准确，请先检查分类结果。

文件内容及内嵌元数据逐字节保留；修改时间尽量保留，原时间记录在清单里。Windows ADS 和 Linux user.* 扩展属性单独复制与检查，不能保留时列出问题并阻止删除提示。创建时间、所有者、ACL 等属性不构成跨平台文件系统备份保证。

符号链接、目录联接和特殊项目不会跟随；它们会列为未处理项。隐藏普通文件和配套文件正常纳入。压缩包作为整体整理；组合媒体的各个文件分别分类，原路径关系保留在清单。

同一目标路径同名同内容时复用已有文件（仍比较内容和附加数据）；不同内容追加 `_001` 等编号保留两份。不同归档路径的重复文件分别保留。中断后继续或重复执行不会覆盖内容不同的文件。

## 命令行

以下 `media-organizer` 在 Windows 下对应 `media-organizer.exe`，Linux 下对应 `./media-organizer`。

```text
media-organizer serve
media-organizer serve --no-browser --port 8731
media-organizer doctor
media-organizer scan SOURCE TARGET --verification full
media-organizer files JOB_ID --page 1
media-organizer edit JOB_ID --ids 1 2 --month 202611 --location CN_Zhejiang_Hangzhou
media-organizer execute JOB_ID --verification full
media-organizer run SOURCE TARGET --verification full --yes
media-organizer verify JOB_ID --verification full
media-organizer jobs
media-organizer config --export config.json
media-organizer config --import config.json
```

全局参数 `--state-dir DIRECTORY` 放在子命令前，可指定状态目录。同一状态目录只允许一个后台/命令行进程执行任务；退出网页后台后可使用命令行，也可用独立状态目录启动独立实例。

## 平台

首版为 Windows x64、Ubuntu 22.04 及更新 LTS x64 / glibc 系统准备。两个系统各自在本平台构建、验收。发行包是否已完成该平台测试，以交付报告记录为准。

本机服务默认只监听 `127.0.0.1`，网页及功能资源均由本地提供。地理数据来自 GeoNames，CC BY 4.0；版本与出处可在设置页及发行包资源清单查看。
